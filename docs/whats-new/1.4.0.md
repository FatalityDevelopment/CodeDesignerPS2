# v1.4.0 — What's New

- **Assets editors** — New *Assets* menu category. The Zipper workbench is now the *Viewer*, joined by **Model**, **Animation** and **Map** editors for SOCOM II and SOCOM: Combined Assault.
- **SOCOM II online** — Briefing rooms, default games, joining, friends, ignore list, rankings, clans, chat, bans, news and patch download all work on real hardware.
- **12v12 and bots** — Larger lobbies, extra online maps and a script that joins simulated players into your lobby.
- **SOCOM CA ports** — CA characters, weapons, vehicles, props and animations run inside SOCOM II.
- **Player tools** — `giveweapon`, `revive`, `kill`, `respawn`, `prop` and more, plus custom weapon HUD icons.
- **AI chat** — New chat panel with ASM highlighting that matches the disassembler.
- **Cheats editor** — Syntax highlighting, archive refresh, cheat annotations in the debugger, address links that navigate correctly.
- **CDS** — Run action, compiler output channel, and fixes for 9-digit immediates, FPU/COP instructions and label operands.
- **Discord bot** — Posts AI activity to a channel.
